# 메일 답장 초안

## 순서
1. 받은 메일에서 뽑는다: 보낸 사람 · 요청 사항 · 기한 · 답해야 할 질문.
2. 말투와 길이를 정한다. 사용자가 안 정했으면 기본 = 정중 · 보통. 고를 수 있다고 한 줄로 알린다.
   - 정중: 존댓말, 인사·맺음말 갖춤
   - 친근: 존댓말이지만 부드럽게, 인사 짧게
   - 간결: 인사 한 줄, 요점만
   - 길이: 짧게 3~4문장 · 보통 5~8문장 · 자세히 문단 2~3개
3. 기한이 "다음 주 금요일" 처럼 상대적이면 date_calc 로 날짜·요일을 정확히 적는다.
4. 초안을 준다: 제목(Re: …) · 본문. 사용자가 채워야 할 곳은 [대괄호] 로 둔다.
5. 초안 아래에 한 줄: 확인할 점 (약속한 날짜, 첨부 여부 등).

## 하지 않는 것
- 사용자가 말하지 않은 약속·수치를 넣지 않는다.
- 메일을 보내지 않는다. 초안만 쓴다.
