# 요약

## 순서
1. 모양을 정한다. 사용자가 안 정했으면 기본 = 3줄 요약. 다른 모양도 된다고 한 줄로 알린다.
   - 3줄: 핵심 · 근거 · 할 일(또는 결론) 한 줄씩
   - 불릿: 5~7개, 한 줄씩, 중요한 순서
   - 표: 항목 · 내용 · 비고 (비교·일정·숫자가 많을 때)
2. 원문 길이가 궁금하면 text_stats 로 세고, 요약 끝에 "원문 N자 → 요약 M자" 를 적는다.
3. 숫자·이름·날짜는 원문 그대로 옮긴다.
4. 원문에 없는 판단은 "내 의견:" 으로 따로 한 줄에 둔다 (사용자가 원할 때만).

## 하지 않는 것
- 원문에 없는 사실을 더하지 않는다.
- 요약이 원문보다 길어지면 안 된다.
