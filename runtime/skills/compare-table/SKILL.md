# 비교표 만들기

## 순서
1. 비교할 후보와 기준을 정한다. 사용자가 기준을 안 줬으면 흔히 쓰는 기준 4~6개를 제안하고 바로 진행한다.
2. 표의 열 = 후보, 행 = 기준. 첫 열은 기준 이름. 후보가 5개를 넘으면 상위 5개만 넣고 나머지는 표 아래 한 줄로.
3. 단위를 맞춘다. 서로 다른 단위(mi·km, lb·kg, GB·GiB 등)는 unit_convert 로 하나로 바꾸고, 바꾼 단위를 기준 이름 옆 괄호에 적는다.
4. 합계·차이·1인당 값 같은 계산은 calculator 로 한다. 암산하지 않는다.
5. 표 아래에 두세 줄:
   - 한 줄 결론: 어떤 상황이면 어떤 후보가 맞는지
   - 확실하지 않은 값 표시: 기억에 기댄 값은 "확인 필요" 를 붙인다

## 결과 모양
- markdown 표 하나 + 결론 줄 + 출처 주의 한 줄
- 출처 주의 문구: "가격·사양은 바뀔 수 있어요. 공식 페이지에서 최신 값을 확인해 주세요."

## 하지 않는 것
- 없는 값을 지어내지 않는다. 모르면 칸에 "—" 를 쓴다.
- 한 후보를 근거 없이 띄우지 않는다.
