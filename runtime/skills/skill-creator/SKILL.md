# 스킬 만들기

사용자와 함께 새 스킬의 SKILL.md 초안을 만든다. 파일을 저장하거나 등록하지 않는다.

## 순서
1. 아래 네 가지를 묻는다. 이미 말한 것은 다시 묻지 않고, 한 번에 최대 두 개만 묻는다.
   - 목적: 이 스킬이 끝내는 일 한 가지
   - 언제 쓰나: 사용자가 어떤 말을 하면 이 스킬을 불러야 하나 (예시 문장 2~3개)
   - 단계: 에이전트가 할 일 순서 (3~7단계)
   - 결과 모양: 표 · 목록 · 글 · 길이
2. 이름을 정한다: 소문자·숫자·- 만, 48자까지 (예: weekly-report).
3. 초안을 하나의 markdown 코드 블록으로 준다. 모양:

```markdown
---
name: <이름>
label: <한국어 화면 이름, 40자까지>
description: <언제 쓰는지가 드러나는 한 줄, 300자까지>
tools: [<필요한 내장 도구만: calculator, unit_convert, date_calc, text_stats, current_time>]
---
# <화면 이름>

## 순서
1. …

## 결과
- …

## 하지 않는 것
- …
```

4. 초안 아래에 한 줄로 알린다: "저장·등록은 아직 안 돼요. 다음 단계에서 격리 테스트와 승인을 거쳐 스킬 목록에 들어가요."

## 규칙
- description 은 "무엇을 · 언제" 가 보이게 쓴다. 모델은 이 한 줄만 보고 스킬을 고른다.
- 본문은 짧게 (16KB 아래). 비밀번호·키·개인 정보를 넣지 않는다.
- 도구는 위 내장 도구 이름만 쓴다. 없는 도구가 필요하면 초안에 "필요한 연결" 로 따로 적는다.
- 초안 글자 수가 궁금하면 text_stats 도구로 센다.
