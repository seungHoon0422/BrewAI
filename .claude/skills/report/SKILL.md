---
name: report
description: 프로젝트 root의 REPORT.html을 현재 상태로 갱신한다(그림 중심, 글 최소). 이전 판은 reports/ 로 보관. 사용자가 /report 를 입력했거나 /wrap 3단계에서 호출할 때만 실행.
---

1. `mkdir -p reports` 후 기존 `REPORT.html` 을 `reports/<YYYY-MM-DD>-<주제>.html` 로 복사한다 (같은 이름이 있으면 `-2`).
2. `REPORT.html` 을 새로 쓴다. 규칙:
   - 맨 위: 한 줄 요약 + Phase 진행 바 + 이번 사이클 데모 결과(된다/안 된다) + 👤 결정 필요 개수.
   - 바뀐 아키텍처·흐름은 인라인 SVG 그림으로. 문단 금지 — 카드, 짧은 표, 그림만. 같은 말을 두 번 쓰지 않는다.
   - "결정 필요" 카드는 최대 3개, 각각 추천 1개 + 대안 1개.
   - 외부 리소스 없는 단일 파일, 라이트·다크 모드 모두 읽히게, 폰 폭에서 가로 스크롤 없게.
3. 채팅에는 한 줄 요약 + 파일 링크만 남긴다.
