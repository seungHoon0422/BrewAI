# slice 07 · 파일 (올리기 · 관리 · 모델별 전달 · 보내기 전에 '어떻게 가는지' 보이기)

- 목표: 대화 · 프로젝트에 파일을 올리고, 스페이스 '파일' 화면에서 한곳에 관리한다. 모델마다 볼 수 있는 모양(그대로 · 쪽 그림 · 문서 속 그림 + 글)으로 바꿔 보낸다 (ADR-0015).
- 결정 (2026-11-03 사용자): 관리 = 대화 첨부 + 프로젝트 파일 + 스페이스 '파일' 화면 · 형식 = 이미지 · PDF · 글(코드 · CSV · MD · JSON) · Office(docx · xlsx · pptx) · 진행 = 한 세션에서 차례대로.
- 로드맵: 07 파일 → 08 승인 카드 → 09 trace (옛 07 · 08 을 한 칸씩 민다).

## 어디에 붙나 (관리 단위)
| 단위 | 누가 보나 | 대화에 어떻게 |
|---|---|---|
| 대화 첨부 | 그 대화를 볼 수 있는 사람 | 보낸 그 턴에만 원본 (다음 턴부터는 이름 한 줄 + `read_file`) |
| 프로젝트 파일 | 프로젝트를 볼 수 있는 사람 | 그 프로젝트의 모든 대화 지침 뒤에 목록 한 줄 (`read_file` 로 읽는다) |
| 스페이스 '파일' 화면 | 스페이스 멤버 | 위 둘을 한곳에 (어디에 붙었나 · 크기 · 올린 사람 · 지우기) |

권한 판정은 서버가 대화 · 프로젝트 · 스페이스 규칙 그대로 (`scopes.py` · guard). 지우면 원본과 뽑은 글을 같이 지운다 (기록에는 '지운 파일' 이름만 남음).

## 저장
- 원본 = conductor 데이터 폴더 `files/<sha256 앞 2자>/<sha256>` (같은 내용은 한 번만) · 메타 = `files` 표 · 뽑은 글 = `file_chunks` 표 (쪽 · 시트 · 슬라이드 단위).
- 올리기 = `PUT /api/files?space=&project=&thread=&name=` 본문 그대로 (multipart 의존성 없음) · 25MB · 사용자당 2GB.
- 형식은 확장자가 아니라 앞 바이트로 판정 (png · jpeg · webp · gif · pdf · zip(Office) · UTF-8 글). 모르는 형식 = 거절.
- Office = 표준 `zipfile` + XML 로 글만 뽑는다 (의존성 없음) · 압축 푼 크기 합 100MB · 항목 2,000개 · `<!DOCTYPE` 이 든 XML 거절 (XXE · billion laughs). PDF = `pypdf` (쪽 500 · 시간 20초).

## 모델별 전달 (서버 `files.plan` · 화면엔 보이지 않는다 · 2026-11-04 사용자: 글만 뽑으면 문서 속 그림을 못 본다 · 배지 없앰)
| 파일 | 이미지를 보는 모델 | 못 보는 모델 |
|---|---|---|
| 이미지 | 그대로 (올릴 때 긴 쪽 2,048px 로 줄임 · Claude 한 변 8,000px 한도) | 이름만 + 칩에 '이 모델은 볼 수 없어요' |
| PDF | PDF 를 받는 모델 = 그대로 (30쪽 · 10MB) · 아니면 **쪽을 그림으로 그려**(pypdfium2 · 긴 쪽 1,400px · 앞 20쪽) 쪽 글과 함께 | 글 |
| docx · pptx | 글 + **파일 안의 그림**(슬라이드 · 문서 순서 · 20개 · 한 변 8,000px · 5MB 넘는 그림은 뺌) | 글 |
| xlsx · 글 · 코드 | 글 (3,000 토큰 넘으면 앞부분 + 목차 + `read_file`) | 같음 |

- `read_file {file, page?, query?}` = 그 대화 · 프로젝트에 붙은 파일만 · 결과 8KB · 파일이 하나라도 있는 대화에서만 도구 배열에 실림 (hello 는 바이트까지 그대로).
- 지난 턴의 그림 · 원본은 다시 보내지 않는다 → `[첨부 원본: 이름 · read_file 로 다시 읽기]` 한 줄.
- 실패 = 오류 카드에 거절 원문을 그대로 (키처럼 보이는 것은 서버가 가림) · '생각 끄고 다시' 같은 추측 안내 없음.
