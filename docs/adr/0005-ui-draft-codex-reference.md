# ADR-0005 · UI 초안: Codex를 '레퍼런스'로 클린룸 재구성

- 상태: 제안 · 2026-10-28
- 맥락: UI 초안을 빨리 만들되, Codex 같은 검증된 레이아웃을 따라가고 싶다. 디테일·디자인은 이후 바꾼다.
- 결정: 리버스 엔지니어링이 아니라 **레퍼런스 기반 클린룸 재구성**.
  1. 관찰: 공식 문서·런칭 영상·공개 스크린샷만 본다 → **UI 스펙 = `design/prototype.html`** (클릭 가능한 정적 프로토타입).
     구성: 회색 프레임(타이틀바·아이콘 레일) 위 흰 면(사이드바 + 메인) · 빈 화면 + 제안 3줄 · 입력창(프로젝트·앱 연결 칩 / 모델 선택 / 검정 보내기)
     · 작업 중엔 우측 '진행 상황' 패널. 글꼴 Pretendard (Electron은 로컬 번들).
  2. 구현: shadcn/ui(셸) · assistant-ui(대화·입력창) · React Flow(에이전트 팀 그래프). 전부 MIT.
  3. 이벤트 모델: Apache-2.0 공개분인 Codex app-server의 thread / turn / item / approval 구조를 참고 (코드 복사 시 LICENSE·NOTICE 유지).
- 금지: Codex 앱 바이너리(app.asar) 추출·디컴파일, 번들 JS/CSS·아이콘·문구 재사용, 앱 패치 도구 사용.
  근거: OpenAI 이용약관의 리버스 엔지니어링 금지 조항 + 비공개 자산 저작권. 로고·색 조합·타이포·고유 문구도 가져오지 않는다.
- 우리만의 것: 팀 활동 패널 — 메인 에이전트 → 서브에이전트 → 툴 호출을 실시간 그래프 + 타임라인으로. 데이터는 AG-UI 이벤트(사용자용), Langfuse는 관리자·개발용.
