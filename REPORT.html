01에이전트란? 혼란의 원인 = 같은 단어가 층을 넘나듦

정의: LLM이 루프 안에서 툴을 고르고 끝낼 때를 스스로 정함 — Anthropic 표현으로 "LLMs autonomously using tools in a loop" (2025-09). OpenAI·Hugging Face도 같은 뜻.

02당신의 가설 검증

바뀐 건 "누가 찾느냐"(사람 → 에이전트). 안 바뀐 건 "누가 허락하느냐"(여전히 사람·관리자).

채팅 · 능력 획득
◐ 조건부사용자 사전 등록이 사라진다

사라지지 않고 '위로' 이동 — 검수 카탈로그·관리자 정책·플러그인 번들

◐ 조건부에이전트가 찾아서 설치

찾기는 표준(tool search, 커넥터 제안). 설치는 카탈로그 안 + 원클릭 동의까지

◐ 조건부에이전트가 Skill·MCP를 만듦

Skill 초안은 주류, 활성화는 사람 검토. MCP 서버를 새로 만드는 건 드묾

✔ 방향 일치사람은 인증·승인만

MCP 스펙이 이 구조(외부 브라우저 로그인·권한 단계 상승). 고위험 행위 승인은 남음

✔ 확인생성형 UI 채팅

MCP Apps가 첫 공식 확장(2026-01). Claude·ChatGPT·VS Code가 렌더

◐ 조건부모든 걸 채팅 안에서

비밀번호·키는 채팅 폼 금지(스펙) → 외부 브라우저. "채팅에서 시작해 채팅으로 복귀"

인프라
◐ 조건부비용·trace를 OTel로 표준화

모두 OTLP 수신. 단 GenAI 규격은 아직 실험 단계 → 이름·비용 키 맞춤 필요

✔ 확인모델 호출은 게이트웨이 뒤

LiteLLM 등 성숙. 모델 정보까지 API로 제공. 버전·해시 고정이 전제

✔ 확인툴도 게이트웨이로 분리

ContextForge·agentgateway. 최신 MCP 스펙 지원이 선택 기준

✔ 확인conductor가 필요할 때 호출

한 trace로 연결 가능. 연결 설정·카탈로그 스키마는 직접 작성
